🤖 AI used in Smavel

Smavel does not use one hard-coded formula. It asks pre-trained AI language models to rate a destination, then combines their answers.

    🍊 Export for Orange Data Mining

    Every analysis you run is saved as one row in a dataset stored in this browser. Run several countries, download the CSV, then open it in Orange with the File widget.

    How to analyse this in Orange (step by step)

    1. Load and check the data

    • File widget: open smavel_analyses.csv. Set country as a "meta" (text) column and the scores as numeric.
    • Data Table: check every row loaded and see which scores are blank (missing).
    • Feature Statistics: shows the mean, spread and missing values for each criterion.

    2. Explore and compare countries

    • Distributions and Box Plot: how scores such as Public safety or Scams vary across countries.
    • Scatter Plot: for example Affordability against Public safety, labelled by country.
    • Heat Map: all 12 criteria for all countries at a glance.
    • Correlations: which criteria move together.

    3. Find groups of similar countries

    • Distances then Hierarchical Clustering: builds a tree of similar destinations.
    • k-Means: splits countries into groups, such as "safe and costly" or "cheap and risky".
    • PCA or MDS then Scatter Plot: shows the groups on a 2-D map.

    4. Compare the AI models

    • Use groq_score, openrouter_score and cloudflare_score in a Scatter Plot to see where the models agree or disagree.
    • Correlations on those score columns measures agreement between models.
    • Select Rows: keep only rows where ai_models_used is 2 or more for a fairer comparison.

    Tip: you need at least 8 to 10 countries for clustering to mean anything. The scores are AI estimates, not measured facts, so describe results as patterns in AI opinions.
